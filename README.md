# E-Commerce Sales Dashboard (Excel)
## Project Overview
This project is an interactive E-Commerce Sales Dashboard built using Microsoft Excel.

## Skills Used
- Data Cleaning
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Slicers
- Dashboard Design

## Dashboard Features
- Total Sales KPI
- Total Orders KPI
- Top Category
- Top State
- Sales Analysis Charts
- Interactive Filters using Slicers

## Tools Used
- Microsoft Excel
